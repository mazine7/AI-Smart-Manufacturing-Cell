# System Requirements

## 1. Project Overview

AI Smart Manufacturing Cell is an intelligent automated manufacturing system that combines mechanical design, robotics, computer vision, artificial intelligence, and industrial automation.

The system is designed to automatically detect, inspect, classify, and sort manufactured parts.

## 2. Main Objective

The main objective is to develop a smart manufacturing cell capable of performing automated quality inspection and robotic sorting with minimal human intervention.

## 3. System Workflow

1. A manufactured part enters the cell.
2. A conveyor transports the part to the inspection station.
3. A sensor detects the presence of the part.
4. A camera captures an image of the part.
5. A computer vision system processes the image.
6. An AI model determines whether the part is GOOD or DEFECTIVE.
7. The robotic system picks up the part.
8. The robot places the part into the appropriate output bin.
9. Production and inspection data are recorded.
10. The dashboard displays the current system status.

## 4. Main Subsystems

### Mechanical System

- Manufacturing cell frame
- Conveyor system
- Product holders
- Robot mounting structure
- Camera mounting structure
- Good-part bin
- Defective-part bin

### Automation System

- Presence sensors
- Motor control
- Conveyor control
- Robot control
- Emergency stop system
- System state control

### Computer Vision System

- Industrial/USB camera
- Image acquisition
- Image preprocessing
- Object detection
- Defect detection

### Artificial Intelligence

The AI system will classify manufactured parts into different categories.

Initial classification:

- GOOD
- DEFECTIVE

Future versions may include:

- Surface defects
- Dimensional defects
- Missing components
- Incorrect orientation

### Robotics

The robotic subsystem will perform:

- Pick-and-place operations
- Part sorting
- Position control
- Path planning

### Monitoring System

The monitoring system will record and display:

- Total production
- Good parts
- Defective parts
- Defect rate
- System status
- Conveyor status
- Robot status
- Camera status

## 5. Initial Performance Targets

The first prototype should aim to achieve:

- Automated part detection
- Automated image acquisition
- AI-based classification
- Automated robotic sorting
- Real-time system monitoring

Performance targets will be refined after the first prototype and testing phase.

## 6. Future Development

Future versions may include:

- Predictive maintenance
- Digital twin
- Production optimization
- Energy monitoring
- Advanced defect classification
- Autonomous process optimization
